爱奥尼官网迁移实现说明

2026-11-16 · 页面修复、CDN 和英文补全分别记录于 GitHub Issues #1、#2、#3。

设计决策

保留原站46个模板和原始样式，编译至不依赖PHP的运行代码。业务通过数据库与存储接口访问资源；Cloudflare使用D1/R2，Node目标提供MySQL和本地目录适配。双语共享内容ID，译文单独存储、独立发布。

差异与修复

兼容原网址并修复不存在模板的旧链接；补齐移动版数据接口与地图模板语法；团队轮播保留原有静态结构并补上前后切换；防止草稿通过详情页、上一篇/下一篇暴露。新后台重新建立登录与权限边界，不复用旧后台密码。

取舍

重用原模板有利于对照原站，但会保留历史布局方式。初始迁移的私有数据不进入公开仓库，首次导入与日常结构迁移分开。历史图片先迁入对象存储，部署前校验目标账号、数据库、桶和图片可访问性；编译阶段仍可保留本机资源。

待核对事项

已生成并通过后台发布 601 条英文初稿；营销横幅和资源图示提供英文展示，真实项目照片与客户标志保留原貌。地图、视频和客服依赖原第三方账号服务。页面比对使用原模板PHP渲染兼容层，不等同于恢复完整旧应用；16组截图同尺寸，最大像素差异0.5579%。DNS已由Cloudflare托管，根域名和www通过部署配置绑定同一个Worker，规范地址使用https://hnaan.cn。

审查记录

首轮发现并修复新建草稿状态、字段类型、单页与其他实体的插入列、Node后台路径、译文状态与规范网址问题；后续补齐首次种子导入、对象存储迁移验证和发布目录清理。验证证据包括单元/接口测试、固定Node版本构建、MySQL 8.4 CI集成及截图报告；以实际运行结果为准。

最终发布审查：目标清单已加入Git、静态发布目录每次重新生成、R2绑定与验证目标一致；无剩余可操作问题。新账号历史媒体3541个文件已逐文件核对，零差异。

后续页面修复：模板编译器补齐单引号include引用，恢复资源整合、服务等页面的公共布局；首页优势副标题通过限定的inline过滤器保留span强调，后台保存时保留安全格式；兼容资源页旧地图调用，SDK不可用时显示联系方式提示，去掉手机版标识制作页的重复导航，并将语言按钮移出手机菜单按钮的点击区域。新增回归覆盖标题内容/属性边界、后台保存、桌面与手机布局、地图兼容和菜单关闭。
