Issue #2 — Media CDN delivery and upload warmup — 2026-11-16

Design Decisions

R2 remains the source of truth. The storage decorator warms Cache API after uploads; canonical delivery URLs are copied while previews stay on the active origin. Cache hits are reported with X-Media-Cache.

Deviations

A CDN stores copies at individual points of presence. Uploads warm the current node; other nodes fill on demand. This does not require a second permanent object bucket.

Tradeoffs

Unique upload names permit one-day browser caching. Mutable static assets revalidate in browsers, with version-separated seven-day edge caches. Range and If-Range validators preserve safe video seeking. Cache outages fall back to source storage.

Open Questions
