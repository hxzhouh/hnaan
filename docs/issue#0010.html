Issue #10 — Schedule images before the preload scanner — 2026-11-16

Design Decisions

Emit eager loading for the first three desktop or four mobile images (header icons and first banner) and lazy loading for later images in the server HTML. Preserve explicit author loading choices; skip scripts, styles and HTML comments.

Deviations

The prior deferred script assigned lazy loading after the preload scanner had already requested all 28 large article photos. A static dimensions manifest (4,257 original files, respecting EXIF rotation) reserves aspect ratios before download. Existing dimensions are preserved or completed proportionally. Mobile legacy cleanup skips generated dimensions, so the placeholders survive DOM-ready scripts. A zero-specificity height:auto rule overrides generated presentation hints while preserving authored CSS sizing.

Tradeoffs

Original media bytes, URLs and layout remain unchanged. Metadata adds about 200KB of uncompressed source. New unknown filenames keep their authored dimensions and native loading behavior; the legacy manifest describes imported originals only. The CDN remains responsible for original object delivery, not resizing.

Open Questions

Acceptance includes request-scheduling probes before/after and production first-view plus scrolled-image checks. Offscreen lazy images are expected to remain unloaded until approached. Missing originals remain tracked in #5.
