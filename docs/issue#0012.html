Design Decisions

The existing article/case keyword links already retain /en/. Search models now match either the original title or a published English translation, using bound parameters and the same condition for count and results.

Deviations

Tradeoffs

SQLite/D1 and MySQL both support the unquoting JSON ->> operator. Normalize case on both sides for MySQL JSON binary collation; guard invalid JSON before extraction, constrain entity and locale, and retain the public source status guard. This preserves original substring-search semantics without adding an external search provider.
